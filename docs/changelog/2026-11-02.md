### Task B — Hoàn thiện backend và lưu dữ liệu
- **Thay đổi chính:**
  - Tạo `Dish` Entity và `Category` Entity với TypeORM trong MySQL database `my_app`.
  - Xây dựng đầy đủ RESTful API cho món ăn tại `DishesController`:
    - `GET /api/dishes`: Lấy danh sách món ăn thật từ MySQL, hỗ trợ lọc danh mục, tìm kiếm, lọc theo trạng thái mở bán.
    - `GET /api/dishes/categories`: Lấy danh sách danh mục kèm số lượng món thực tế tính tự động.
    - `GET /api/dishes/:id`: Lấy chi tiết món ăn.
    - `POST /api/dishes`: Thêm món mới kèm kiểm tra quyền (`x-staff-id`), validate tên không rỗng, giá nguyên VNĐ không âm, danh mục hợp lệ.
    - `PUT /api/dishes/:id`: Cập nhật thông tin món ăn kèm kiểm tra quyền.
    - `PATCH /api/dishes/:id/status`: Bật/tắt trạng thái còn món/hết món.
    - `DELETE /api/dishes/:id`: Xóa món an toàn. Nếu món đã từng phát sinh trong lịch sử đơn hàng (`table_session_records`), hệ thống tự động chuyển sang lưu trữ (`isArchived: true, isAvailable: false`) để bảo toàn lịch sử; nếu chưa từng bán thì xóa hoàn toàn.
- **Tập tin đã tạo / thay đổi:**
  - `backend/src/dishes/entities/dish.entity.ts`
  - `backend/src/dishes/entities/category.entity.ts`
  - `backend/src/dishes/dto/create-dish.dto.ts`
  - `backend/src/dishes/dto/update-dish.dto.ts`
  - `backend/src/dishes/dto/query-dish.dto.ts`
  - `backend/src/dishes/dishes.service.ts`
  - `backend/src/dishes/dishes.controller.ts`
  - `backend/src/dishes/dishes.module.ts`
  - `backend/src/app.module.ts`
- **Kết quả kiểm chứng:**
  - Chặn quyền nhân viên không phận sự (`staff-4`: HTTP 403).
  - Thêm, sửa, bật/tắt món hoạt động chuẩn xác với nhân viên quản lý (`staff-1`: HTTP 201/200).
  - Món đã từng bán trong đơn (`dish-2`) được tự động lưu trữ (`archived: true`), không xóa cứng làm hỏng dữ liệu liên quan.
  - Linter: `oxlint` 0 warnings, 0 errors; Build: `nest build` thành công.

### Task F — Tinh chỉnh UI/UX với UI UX Pro Max
- **Thay đổi chính:**
  - Tinh chỉnh giao diện `MenuManagementView` theo chuẩn UI UX Pro Max:
    - Bố cục bảng trên màn hình máy tính (`1366x768`): thiết lập chiều rộng tối thiểu và tỷ lệ cột hợp lý, không tràn ngang, typography sắc nét.
    - Bố cục danh sách thẻ trên di động (`390x844`): chuyển đổi mượt mà sang dạng thẻ riêng biệt với hình ảnh, thông tin, trạng thái và nút hành động rõ ràng.
    - Kích thước vùng cảm ứng (touch targets): chuẩn hóa các nút thao tác (chỉnh sửa, xóa, làm mới) tối thiểu 36-44px, bổ sung `aria-label` tăng cường khả năng truy cập (accessibility a11y).
  - Tinh chỉnh hộp thoại xác nhận xóa món:
    - Bổ sung `aria-modal="true"`, `role="dialog"`, `aria-labelledby="delete-dialog-title"`.
    - Hiển thị rõ tên món, cảnh báo cơ chế lưu trữ an toàn thay vì xóa vĩnh viễn khi món đã có lịch sử gọi món.
  - Tinh chỉnh modal thêm / chỉnh sửa món `MenuItemFormModal`:
    - Bổ sung định danh `modal-title` cho tiêu đề hộp thoại.
    - Xem trước thời gian thực thẻ món ăn chuẩn như khách quét QR nhìn thấy.
