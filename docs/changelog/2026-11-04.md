## CẤU HÌNH DEMO ĐẶT MÓN QR TRÊN ĐIỆN THOẠI QUA MẠNG LAN

### 1. Mục Tiêu Triển Khai
- Cho phép thiết bị di động thật (điện thoại thông minh) kết nối cùng mạng Wi-Fi/LAN với laptop có thể quét mã QR thực tế của từng bàn ăn để truy cập thực đơn và gửi gọi món.
- Xử lý vấn đề môi trường cục bộ: thiết lập Vite Proxy chuyển tiếp API `/api/...` về `http://localhost:3000`, giúp điện thoại gọi API mượt mà không gặp lỗi `localhost` hay lỗi CORS.
- Chuẩn hóa mã QR nhúng chính xác địa chỉ IP LAN thật (`192.168.12.75:5173`), xóa bỏ tên miền mẫu `https://huycv.vn`.
- Tuân thủ nguyên tắc tối cao: **Zero Database Interference**.

### 2. Các Thay Đổi Chính
1. **Frontend Scripts & Cấu hình Vite (`frontend/package.json`, `package.json`, `frontend/vite.config.ts`):**
   - Bổ sung lệnh `npm run dev:lan` (`vite --host 0.0.0.0 --port 5173 --strictPort`).
   - Cấu hình Vite Proxy chuyển tiếp các request `/api` và `/health` sang Backend trên port `3000`.
   - Giữ nguyên script `dev`, `dev:front`, `dev:back` chạy bình thường.
2. **Tập trung hóa cấu hình API Client (`frontend/src/services/apiConfig.ts`):**
   - Tạo module tập trung quản lý `API_BASE_URL`.
   - Loại bỏ hoàn toàn `http://localhost:3000` gán cứng trong `api.ts`, `dishesApi.ts`, `bannersApi.ts`, `reportsApi.ts`, `staffApi.ts`.
   - Chuyển sang gọi đường dẫn tương đối `/api/...` để tận dụng Vite Proxy.
3. **Tập trung hóa cơ chế sinh mã QR (`frontend/src/utils/qrConfig.ts`):**
   - Xây dựng module tiện ích tính toán Base URL công khai cho điện thoại (`getPublicBaseUrl()`).
   - Tự động sử dụng IP LAN `192.168.12.75:5173` khi mở từ laptop trên localhost.
   - Hàm `buildTableOrderUrl` và `buildTableQrCodeUrl` được tích hợp đồng bộ vào `mockData.ts`, `RestaurantContext.tsx` và `TableQrConfigModal.tsx`.
   - Hiển thị trực quan đường dẫn truy cập và nút in/tải mã QR trong modal cấu hình bàn.
4. **Tài liệu hướng dẫn thử nghiệm:**
   - Tạo cẩm nang chi tiết tại `docs/testing/lan-qr-demo-guide.md` với danh sách link trực tiếp và mã QR của 8 bàn ăn.
   - Thêm file mẫu cấu hình `frontend/.env.example`.
